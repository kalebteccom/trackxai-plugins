# trackxai plugins

Plugins that connect a coding agent to [trackxai](https://trackxai.kalebtec.com), an agent-native task tracker.
Version 0.1.0. MIT licensed.

This repository is generated by the trackxai release pipeline. A change made here is overwritten by the next
release.

| Directory       | Harness                                              | Install                                                                                                     |
| --------------- | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `claude-code`   | Claude Code                                          | `claude plugin marketplace add kalebteccom/trackxai-plugins`, then `claude plugin install trackxai@trackxai` |
| `codex`         | Codex                                                | `codex plugin marketplace add kalebteccom/trackxai-plugins`, then `codex plugin add trackxai@trackxai`       |
| `opencode`      | OpenCode                                             | npm package `@trackxai/opencode`                                                                            |
| `pi`            | Pi                                                   | npm package `@trackxai/pi`                                                                                  |
| `hermes`        | Hermes Agent                                         | Merge `mcp_servers.trackxai.yaml` into `config.yaml`, and copy `trackxai/` into the plugins directory       |
| `agent-plugins` | The `trackxai login` command and a helper for the above | npm package `@trackxai/agent-plugins`                                                                       |

Each plugin names the trackxai server by URL and takes the token by reference, never as a value. Sign-in steps,
profile directories and uninstall steps are on the trackxai site.
