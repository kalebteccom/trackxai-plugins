# trackxai for Claude Code

![trackxai](.claude-plugin/icon.png)

Task tracker for AI agents. They file tasks and raise questions over MCP, and you triage them on a board.

trackxai is a task tracker that AI agents write into and a person triages. Connect it and your assistant can read your workspace, pick up a task, record progress on it and mark it done, in the workspace you choose when you sign in, or in every workspace you belong to in that account.

Every task holds named fields: a title, a goal, what is out of scope and at least one acceptance criterion. A write that leaves a required field empty is refused with the fix, so work lands complete. When an agent meets something it does not know, it raises a gap. A gap says who must answer, and the answer lands back on the task.

Ask your assistant to list the tasks and epics in a workspace, read one task in full, show the gaps waiting on you, claim a task and log progress, draft an epic with its tasks, or summarise what changed since yesterday.

Sign-in uses OAuth. You pick one workspace, or choose All my workspaces. One workspace limits the connection to it. All my workspaces reaches every workspace you belong to in that account, including ones you join later, and loses a workspace when you leave it. It never reaches another account. Writes carry your own permission, so a connection made by a viewer stays read-only. You can revoke a connection at any time from Agent tokens in trackxai.

## What the plugin adds

- One remote MCP server, `trackxai`, over HTTP at <https://trackxai.kalebtec.com/mcp>. Its tools read and write the
  trackxai workspaces you allow when you sign in.
- One skill, `trackxai`, which teaches Claude how to claim a task, record progress and evidence, and
  write tasks and questions a person can act on.

It has no hooks, commands, agents or scripts, and it runs no code on your machine. Nothing is
downloaded at install time beyond the files in this folder.

## Install

You need a trackxai account and a workspace. Sign up at <https://trackxai.kalebtec.com>.

In a terminal:

```
claude plugin marketplace add kalebteccom/trackxai-plugins
claude plugin install trackxai@trackxai
```

Inside a Claude Code session the same two steps are `/plugin marketplace add kalebteccom/trackxai-plugins` and
`/plugin install trackxai@trackxai`.

## Sign in

Start Claude Code, run `/mcp`, pick `trackxai` and choose to authenticate. Your browser opens trackxai's
sign-in page. Sign in, pick one workspace or All my workspaces, and approve. Claude Code keeps the
resulting OAuth token in its own credential store. No file in this plugin holds a token, and there is
nothing to paste.

You can revoke the connection at any time from Agent tokens in trackxai.

## Settings

The plugin has one option, `url`, the address of the trackxai MCP server. It defaults to
<https://trackxai.kalebtec.com/mcp>. Change it only for a self-hosted trackxai server.

## What it sends, and where

Claude Code sends each trackxai tool call, with the arguments Claude chose, to the MCP server above,
and nowhere else. The server answers with the records the call asked for. The plugin sends nothing on
its own: no telemetry, no analytics, and no request to any other host.

What trackxai stores is what your agents and you write into a workspace: tasks, epics, comments,
progress notes, questions and their answers, attachments, and an append-only record of who changed
what. A tool call can only reach the workspaces you approved at sign-in, with your own permission in
each.

## Check, update and remove

- Check: `claude mcp get plugin:trackxai:trackxai`
- Update: `claude plugin marketplace update trackxai`, then `claude plugin update trackxai@trackxai`
- Remove: `claude plugin uninstall trackxai@trackxai`, then `claude plugin marketplace remove trackxai`
